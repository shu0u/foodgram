# Foodgram

Foodgram - это веб-приложение, в котором пользователи могут публиковать рецепты, подписываться на других авторов и формировать список покупок.

## Адрес проекта

🌐 **https://foodgram-shu0u.dynv6.net/**

## Стек технологий

- Python 3.12
- Django 4.2
- Django REST Framework
- PostgreSQL
- Docker
- Nginx
- GitHub Actions
